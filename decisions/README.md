# Decisions

This directory holds Architecture Decision Records (ADRs) for `wot-spec`. ADRs record spec-level decisions whose rationale would otherwise be lost in PR descriptions — typically resolutions of normative ambiguities, conformance-bar choices, or other decisions that the normative spec text alone would not fully explain. ADRs are not themselves normative; they explain *why* the normative text is shaped the way it is. They are linked from the relevant spec documents and from `CONFORMANCE.md` when applicable.
